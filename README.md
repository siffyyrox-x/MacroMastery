# MacroMastery

An interactive macroeconomics study guide I built during my Macroeconomics course to make learning the subject more structured, visual, and engaging.

Instead of relying only on traditional notes, I designed this project as an interactive revision system where important concepts, formulas, graphs, common mistakes, and exam topics can be studied in one place.

## Topics Covered

- GDP and Economic Growth
- Jobs and Unemployment
- Inflation and Price Levels
- Aggregate Demand and Aggregate Supply
- Economic Growth and Business Cycles
- Money and Banking
- Monetary Policy
- Fiscal Policy
- Government Spending and Taxes
- Core Macroeconomic Formulas
- Exam-focused Questions and Revision

## Features

- Interactive topic navigation
- Simplified explanations of difficult concepts
- Important formulas and calculation methods
- Common exam traps and mistakes
- Graph-based explanations
- Quick revision sections
- Structured chapter-by-chapter learning
- Dark, distraction-free interface

## Why I Built It

I created MacroMastery while taking my Macroeconomics course because I wanted a more interactive way to understand and revise the entire syllabus.

The goal was to turn course materials into a study tool that helps me **understand concepts instead of simply memorizing them**.

## Built With

- HTML
- CSS
- JavaScript

## Purpose

This is primarily a personal learning project, combining web development with my Macroeconomics coursework.
